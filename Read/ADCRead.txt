 ADC 双路测频模块使用说明(ADCRead)
 模块文件: User/ADC.c + User/ADC.h
 更新日期: 2026-09-09
 方案: 方案1(ADC1=PA4 测 PWM1 回环, ADC2=PA5 测 PWM2 回环)
================================================================================

一、功能概述
--------------------------------------------------------------------------------
1. 双 ADC 方案: ADC1 连续采样 PA4, ADC2 连续采样 PA5, 两路各自独立统计,
   互不干扰(非双 ADC 同步模式, 两路顺序采样, 每路采样率 = 主循环频率)。
2. "过零计数法"测量方波 PWM: 对输入电压高速 ADC 采样, 带迟滞的阈值判定
   高低电平, 在 1s 窗口内统计:
      - 上升沿个数           => 频率(分辨率 1Hz)
      - 高电平采样点占比     => 占空比(分辨率 1%)
3. 适用信号: 0~3.3V 干净方波, 频率建议 10Hz~10kHz(每周期至少 10 个采样点);
   用途: 回环自测本机 PWM(PA6/PA7), 或接外部信号发生器测量任意方波源。
4. 测量期间主循环忙于采样(CPU 占用高), 但按键扫描在 TIM2 中断中完成,
   按键响应不受影响。

二、引脚与接线
--------------------------------------------------------------------------------
  引脚    | ADC 通道    | 被测对象(回环自测)          | 代码中名称
  --------|-------------|-----------------------------|----------------
  PA4     | ADC1_IN4    | PWM1 回环(接 PA6)          | Sel=0
  --------|-------------|-----------------------------|----------------
  PA5     | ADC2_IN5    | PWM2 回环(接 PA7)          | Sel=1
  --------|-------------|-----------------------------|----------------
接线要求: 被测信号必须是 0~3.3V 方波, 且与开发板共地;
         输入电压严禁超过 3.3V, 接 5V 信号必须先分压(否则可能损坏引脚);
         回环自测用两根杜邦线: PA6 -> PA4, PA7 -> PA5。
引脚占用核对: PA4/PA5 为纯 ADC 输入脚(不占 PWM/按键/OLED/SWD 引脚),
与工程现有外设均无冲突。

三、对外接口函数
--------------------------------------------------------------------------------
1) void ADCx_Init(void)
   功能: 使能 ADC1/ADC2 与 GPIOA 时钟, ADC 时钟 = PCLK2/6 = 12MHz;
         PA4/PA5 配置模拟输入; ADC1 固定 IN4、ADC2 固定 IN5(采样时间 1.5周期);
         单次转换模式(软件触发), 使能并校准两片 ADC。
   注意: 本模块不开启任何中断与 DMA。

2) void ADCx_Poll(void)
   功能: 主循环每轮调用一次: 两路各触发一次转换、读值、判电平并累计;
         1s 窗口(由 g_msTick 计时)满后结算出频率/占空比并自动开下一窗口。
   依赖: main.c 中 volatile uint32_t g_msTick(TIM2 中断每 1ms 累加)。

3) uint8_t ADCx_ResultReady(void)   // 返回 1 表示 1s 窗口结算完成有新结果
4) void ADCx_ResultClear(void)      // 读取结果后清除标志
5) uint32_t ADCx_GetFreqHz(uint8_t Sel)   // 取频率(Hz): 0=PA4, 1=PA5
6) uint8_t ADCx_GetDutyPct(uint8_t Sel)   // 取占空比(%): 0=PA4, 1=PA5

四、测量原理与参数(ADC.c 顶部宏)
--------------------------------------------------------------------------------
 - 采样时间 ADC_SampleTime_1Cycles5: 单次转换约 14 个 ADC 时钟(~1.2us),
   实际采样率受主循环开销限制, 约 20万~30万点/秒/路;
 - 迟滞阈值: ADC_LEVEL_HI=2304(≈1.86V) 判高, ADC_LEVEL_LO=1792(≈1.44V)
   判低, 中间区间保持原电平 —— 防止临界抖动造成多计沿;
 - 窗口 ADC_WIN_MS=1000(ms): 频率分辨率 1Hz; 改小可提高刷新率但分辨率
   同步变差(分辨率 = 1000/窗口ms);
 - 频率 = 窗口内上升沿数 x 1000 / 实际窗口时长(ms);
 - 占空比 = 高电平采样点数 x 100 / 总采样点数(四舍五入)。

五、main.c 集成方式与 OLED 显示
--------------------------------------------------------------------------------
   显示布局(OLED 4行 x 16列, ASCII):
     第1行: F1:01000 D1:050%   (PA4 实测频率 Hz / 占空比 %)
     第2行: F2:01000 D2:050%   (PA5 实测频率 Hz / 占空比 %)
     第3行: 1:+10% 2:-10%      (按键图例: 单击/双击)
     第4行: 3(Long)=50%        (按键图例: 长按恢复 50%)
   OLED 只在测量数值变化时才刷新(采样不被周期性打断, 读数误差<0.3%)。

六、验证情况(实测预期)
--------------------------------------------------------------------------------
 - 回环自测(PA6→PA4, PA7→PA5): 上电显示 F1/F2≈01000Hz, D≈050%;
 - 单击 Key1 把 PWM1 调到 80%: 约 1s 内 D1 显示跟随到 080%±2%;
 - 占空比调到 0%/100% 时无翻转沿, 对应通道频率显示 0(正常现象);
 - 信号发生器测试: 输出 0~3.3V 方波接入 PA4/PA5(拔掉回环线即可),
   100Hz~10kHz 内频率读数误差 ±1Hz 以内。
   注: 先本机自测通过后, 信号发生器测外部信号只需换接线, 无需改代码。

七、注意事项与局限性
--------------------------------------------------------------------------------
 1. 本模块靠"采样点判电平"换算频率, 只适用于干净的 0~3.3V 方波;
    若输入是缓慢/带噪声/幅值过小的信号, 读数不可信。
 2. 频率 >10kHz 时每周期采样点减少, 频率仍大致可读, 但占空比误差增大;
    要精确测量任意波形的频率/占空比, 应改用定时器输入捕获方案。
 3. 输入电压严禁超过 3.3V(VDDA), 5V 信号必须先分压, 否则可能损坏芯片。
 4. 未接线(PA4/PA5 悬空)时采样到的是环境噪声, 频率读数无意义,
    调试时务必先接好回环线或信号源。
 5. 按键调节的是"本机 PWM 输出"的占空比; 若测量外部信号发生器,
    按键对被测信号无影响(读数只反映外部信号)。
 6. 若改用其他时基提供 1ms(g_msTick), 只需保证每 1ms 调用一次递增;
    g_msTick 由 main.c 中 TIM2_IRQHandler 累加, 删除该累加将导致
    窗口永不结算(频率始终显示旧值)。
