一、已使用引脚记录(当前可运行固件: PWM输出 + ADC回环测频, OLED显示, 按键调占空比)
--------------------------------------------------------------------------------
  引脚    | 方向/模式      | 用途               | 代码中的名称/宏(所在文件)
  --------|----------------|--------------------|--------------------------------
  PB1     | 输入-下拉(IPD) | Key1 按键           | KEY1_PORT/KEY1_PIN=GPIO_Pin_1
          |                | (单击+10%/双击-10% | 动作状态: KeyAction1(Key.h)
          |                |  /长按50%, 调PWM1)  | 处理: Key_Service(main.c)
  --------|----------------|--------------------|--------------------------------
  PB11    | 输入-下拉(IPD) | Key2 按键           | KEY2_PORT/KEY2_PIN=GPIO_Pin_11
          |                | (同上, 调PWM2)     | 动作状态: KeyAction2(Key.h)
  --------|----------------|--------------------|--------------------------------
  PA6     | 复用推挽输出    | PWM1 输出           | TIM3_CH1, PWM1_SetDuty(User/PWM.c)
          | (AF_PP)        | 1kHz, 占空比0~100%  | 引脚: GPIO_Pin_6(GPIOA)
  --------|----------------|--------------------|--------------------------------
  PA7     | 复用推挽输出    | PWM2 输出           | TIM3_CH2, PWM2_SetDuty(User/PWM.c)
          | (AF_PP)        | 1kHz, 占空比0~100%  | 引脚: GPIO_Pin_7(GPIOA)
  --------|----------------|--------------------|--------------------------------
  PA4     | 模拟输入(AIN)  | 输入PWM1(回环测频)  | ADC1_IN4, Sel=0(User/ADC.c)
          |                | 自测接 PA6          | 结果: ADCx_GetFreqHz/DutyPct(0)
  --------|----------------|--------------------|--------------------------------
  PA5     | 模拟输入(AIN)  | 输入PWM2(回环测频)  | ADC2_IN5, Sel=1(User/ADC.c)
          |                | 自测接 PA7          | 结果: ADCx_GetFreqHz/DutyPct(1)
  --------|----------------|--------------------|--------------------------------
  PB8     | 开漏输出(软件   | OLED 时钟线 SCL    | OLED_W_SCL(GPIO_Pin_8, OLED.c)
          | I2C)            |                    |
  --------|-----------------|--------------------|--------------------------------
  PB9     | 同上            | OLED 数据线 SDA    | OLED_W_SDA(GPIO_Pin_9, OLED.c)
  --------|-----------------|--------------------|--------------------------------
  PA13    | 调试口 SWDIO    | ST-Link 下载调试   | 系统占用, 应用代码勿复用
  PA14    | 调试口 SWCLK    | ST-Link 下载调试   | 系统占用, 应用代码勿复用
  --------|----------------|--------------------|--------------------------------
  (不占引脚)  TIM2        | 1ms 时基            | Timer_Init()/TIM2_IRQHandler
          | (定时器内部计数) | 按键扫描节拍        | (main.c); 中断内累加 g_msTick
          |                | + ADC测频窗口计时   | 供 User/ADC.c 使用
  --------|----------------|--------------------|--------------------------------
  (不占引脚)  TIM3        | 双通道 PWM 时基      | PWM_Init()(User/PWM.c), 1kHz
  --------|----------------|--------------------|--------------------------------
  (不占引脚)  ADC1/ADC2   | 过零计数测频        | ADCx_Init/Poll(User/ADC.c)
  --------|----------------|--------------------|--------------------------------
  回环自测接线: PA6 -> PA4, PA7 -> PA5(两根杜邦线);
  外部信号测试: 拔掉回环线, 将 0~3.3V 方波信号源接入 PA4/PA5(需共地)。
  注意: 输入电压严禁超过 3.3V!

三、工程定义的头文件及其简要功能
--------------------------------------------------------------------------------
  头文件               | 所属模块       | 简要功能
  ---------------------|----------------|----------------------------------------
  Key.h                | User/按键模块  | 按键动作枚举(Waiting/OneButton/
                       |                |   TwoButton/LongButton)、动作状态变量
                       |                |   KeyAction1/KeyAction2 的 extern 声明、
                       |                |   Key_Init/Key_Clear/Key_Tick 函数声明
                       |                |   及使用说明注释; 当前用于调两路PWM占空比
  ---------------------|----------------|----------------------------------------
  PWM.h                | User/PWM模块   | 双通道PWM输出声明: PWM_Init(初始化,
                       |                |   PA6/PA7=TIM3_CH1/CH2, 1kHz, 默认50%)、
                       |                |   PWM1_SetDuty/PWM2_SetDuty(设占空比0~100)
                       |                |   详见 Read/PWMRead.txt
  ---------------------|----------------|----------------------------------------
  ADC.h                | User/测频ADC   | 双路ADC测频声明: ADCx_Init(PA4=ADC1_IN4,
                       |                |   PA5=ADC2_IN5)、ADCx_Poll(每轮采样)、
                       |                |   ADCx_ResultReady/Clear、ADCx_GetFreqHz/
                       |                |   ADCx_GetDutyPct(取频率Hz/占空比%)
                       |                |   过零计数法, 详见 Read/ADCRead.txt
  ---------------------|----------------|----------------------------------------
  OLED.h               | HardWare/显示  | OLED 显示驱动接口声明: OLED_Init(初始化)、
                       |                |   OLED_Clear(清屏)、OLED_ShowChar/ShowString
                       |                |   (显示字符/字符串)、OLED_ShowNum/
                       |                |   ShowSignedNum/ShowHexNum/ShowBinNum
                       |                |   (显示无符号/有符号/十六进制/二进制数字)
  ---------------------|----------------|----------------------------------------
  OLED_Font.h          | HardWare/显示  | OLED 字模数据(ASCII 8x16 点阵取模表),
                       |                |   供 OLED.c 显示字符时查表使用
  ---------------------|----------------|----------------------------------------
  Delay.h              | System/延时    | 阻塞式延时函数声明: Delay_us(微秒)、
                       |                |   Delay_ms(毫秒)、Delay_s(秒)
                       |                |   实现基于 SysTick 轮询, 默认按 72MHz
                       |                |   (当前固件未调用)
  ---------------------|----------------|----------------------------------------
  stm32f10x_it.h       | User/中断      | 中断服务函数声明(NMI/HardFault/
                       |                |   SysTick 等), 工程内 TIM2_IRQHandler
                       |                |   实际定义在 main.c
  ---------------------|----------------|----------------------------------------
  stm32f10x_conf.h     | User/库配置    | 标准外设库配置文件: 统一包含所需外设
                       |                |   头文件(如 stm32f10x_gpio/tim/rcc.h)、
                       |                |   assert_param 宏开关
  ---------------------|----------------|----------------------------------------
  stm32f10x.h          | Start/设备头   | STM32F10x 设备寄存器定义与中断号定义,
                       |                |   工程需定义 STM32F10X_MD 与
                       |                |   USE_STDPERIPH_DRIVER 宏
  ---------------------|----------------|----------------------------------------
  RTE_Components.h     | 工程根目录     | eIDE 自动生成组件头(当前为空壳)

四、当前宏定义说明(eIDE 工程 defineList)
--------------------------------------------------------------------------------
  USE_STDPERIPH_DRIVER : 使用标准外设库(使 stm32f10x.h 自动包含 stm32f10x_conf.h)
  STM32F10X_MD         : 目标器件为中容量(64KB Flash), STM32F103C8 必需
