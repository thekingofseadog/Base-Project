一、已使用引脚记录(当前可运行固件: OLED按键测试程序)
--------------------------------------------------------------------------------
 引脚    | 方向/模式      | 用途               | 代码中的名称/宏(所在文件)
 --------|----------------|--------------------|--------------------------------
 PB1     | 输入-下拉(IPD) | Key1 按键          | KEY1_PORT/KEY1_PIN=GPIO_Pin_1
         |                |                    | 动作状态: KeyAction1(Key.h)
 --------|----------------|--------------------|--------------------------------
 PB11    | 输入-下拉(IPD) | Key2 按键          | KEY2_PORT/KEY2_PIN=GPIO_Pin_11
         |                |                    | 动作状态: KeyAction2(Key.h)
 --------|----------------|--------------------|--------------------------------
 PB8     | 开漏输出(软件   | OLED 时钟线 SCL   | OLED_W_SCL(GPIO_Pin_8, OLED.c)
         | I2C)            |                    |
 --------|-----------------|--------------------|--------------------------------
 PB9     | 同上            | OLED 数据线 SDA   | OLED_W_SDA(GPIO_Pin_9, OLED.c)
 --------|----------------|--------------------|--------------------------------
 PA13    | 调试口 SWDIO    | ST-Link 下载调试   | 系统占用, 应用代码勿复用
 PA14    | 调试口 SWCLK    | ST-Link 下载调试   | 系统占用, 应用代码勿复用
 --------|----------------|--------------------|--------------------------------
 (不占引脚)  TIM2        | 1ms 时基          | Timer_Init()/TIM2_IRQHandler
         | (定时器内部计数) | (按键扫描节拍)     | (main.c)

三、工程定义的头文件及其简要功能
--------------------------------------------------------------------------------
 头文件               | 所属模块       | 简要功能
 ---------------------|----------------|----------------------------------------
 Key.h                | User/按键模块  | 按键动作枚举(Waiting/OneButton/
                      |                |   TwoButton/LongButton)、动作状态变量
                      |                |   KeyAction1/KeyAction2 的 extern 声明、
                      |                |   Key_Init/Key_Clear/Key_Tick 函数声明
                      |                |   及使用说明注释
 ---------------------|----------------|----------------------------------------
 OLED.h               | HardWare/显示  | OLED 显示驱动接口声明: OLED_Init(初始化)、
                      |                |   OLED_Clear(清屏)、OLED_ShowChar/ShowString
                      |                |   (显示字符/字符串)、OLED_ShowNum/
                      |                |   ShowSignedNum/ShowHexNum/ShowBinNum
                      |                |   (显示无符号/有符号/十六进制/二进制数字)
 ---------------------|----------------|----------------------------------------
 OLED_Font.h          | HardWare/显示  | OLED 字模数据(ASCII 6x8 点阵取模表),
                      |                |   供 OLED.c 显示字符时查表使用
 ---------------------|----------------|----------------------------------------
 Delay.h              | System/延时    | 阻塞式延时函数声明: Delay_us(微秒)、
                      |                |   Delay_ms(毫秒)、Delay_s(秒)
                      |                |   实现基于 SysTick 轮询, 默认按 72MHz
 ---------------------|----------------|----------------------------------------
 stm32f10x_it.h       | User/中断      | 中断服务函数声明(NMI/HardFault/
                      |                |   SysTick 等), 工程内 TIM2_IRQHandler
                      |                |   实际定义在 main.c
 ---------------------|----------------|----------------------------------------
 stm32f10x_conf.h     | User/库配置    | 标准外设库配置文件: 统一包含所需外设
                      |                |   头文件(如 stm32f10x_gpio/tim/rcc.h)、
                      |                |   assert_param 宏开关
 ---------------------|----------------|----------------------------------------
 stm32f10x.h          | Start/设备头   | STM32F10x 设备寄存器定义与中断号定义,
                      |                |   工程需定义 STM32F10X_MD 与
                      |                |   USE_STDPERIPH_DRIVER 宏
 ---------------------|----------------|----------------------------------------
 RTE_Components.h     | 工程根目录     | eIDE 自动生成组件头(当前为空壳)
================================================================================

四、当前宏定义说明(eIDE 工程 defineList)
--------------------------------------------------------------------------------
 USE_STDPERIPH_DRIVER : 使用标准外设库(使 stm32f10x.h 自动包含 stm32f10x_conf.h)
 STM32F10X_MD         : 目标器件为中容量(64KB Flash), STM32F103C8 必需
