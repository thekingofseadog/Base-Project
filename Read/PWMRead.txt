 PWM 双通道输出模块使用说明(PWMRead)
 模块文件: User/PWM.c + User/PWM.h
 更新日期: 2026-09-09
 方案: 方案1(PWM1=PA6, PWM2=PA7, TIM3_CH1/CH2)
================================================================================

一、功能概述
--------------------------------------------------------------------------------
1. 基于 TIM3 的双通道 PWM 输出: PWM1 = PA6(TIM3_CH1), PWM2 = PA7(TIM3_CH2)。
2. 输出频率默认 1kHz(固定), 占空比 0~100% 可随时调用 PWM1_SetDuty() /
   PWM2_SetDuty() 更新, 占空比精度 1%(默认 ARR=99, CCR 数值即百分数)。
3. 上电默认两路 50%; 输出完全由硬件产生, 不占用 CPU, 不开任何中断。
4. 与按键联动(逻辑在 main.c 的 Key_Service): Key1 调 PWM1、Key2 调 PWM2,
   单击 +10%、双击 -10%、长按恢复 50%(回绕: 100% 再单击回 0%, 0% 再双击回 100%)。
5. 与 ADC 测频模块联动: PA6→PA4、PA7→PA5 杜邦线回环, 由 ADC 模块测回
   频率与占空比并在 OLED 显示(见 ADCRead.txt)。

二、引脚与硬件
--------------------------------------------------------------------------------
  引脚    | 功能         | 代码名称                 | GPIO 模式
  --------|--------------|--------------------------|----------------
  PA6     | PWM1 输出    | TIM3_CH1 / PWM1_SetDuty | 复用推挽(AF_PP)
  --------|--------------|--------------------------|----------------
  PA7     | PWM2 输出    | TIM3_CH2 / PWM2_SetDuty | 复用推挽(AF_PP)
  --------|--------------|--------------------------|----------------
  电平    | 0~3.3V 方波  | 高电平=3.3V              | 大负载需外部驱动
--------------------------------------------------------------------------------
引脚占用核对(与工程其他模块无冲突): 按键 PB1/PB11、OLED PB8/PB9、
SWD PA13/14、8MHz 晶振 PD0/PD1 均不受影响; 无需任何重映射;
TIM3 与 TIM2(1ms 时基)是不同定时器, 互不干扰。

三、对外接口函数
--------------------------------------------------------------------------------
1) void PWM_Init(void)
   功能: 使能 GPIOA/TIM3 时钟, PA6/PA7 配置复用推挽, TIM3 时基
         (计数 100kHz, 周期 100 点 => 1kHz), CH1/CH2 PWM1 模式初始化,
         初始占空比 50%, 启动 TIM3。
   注意: 本函数不配置中断、不依赖 main.c 的 Timer_Init(TIM2)。

2) void PWM1_SetDuty(uint8_t Percent)   // PWM1(PA6), 0~100
3) void PWM2_SetDuty(uint8_t Percent)   // PWM2(PA7), 0~100
   功能: 立即更新对应通道占空比(经预装载, 下个周期生效, 无跳变)。
   参数: 0 = 恒低, 100 = 恒高(CCR=100 > ARR=99, 输出全程高电平)。
   注意: 输入 >100 时内部钳位到 100。

四、输出频率修改方法(原理)
--------------------------------------------------------------------------------
   PWM.c 顶部宏:
     PWM_TIM_CLK = 72000000   TIM3 输入时钟(APB1=36MHz, 定时器自动 x2)
     PWM_ARR     = 99         每周期 100 个计数点(决定占空比分辨率 1%)
     PWM_PSC     = 719        计数频率 100kHz

   输出频率 f = 72MHz / ((PWM_PSC+1) x (PWM_ARR+1)) = 1kHz
   改频率只需改 PWM_PSC: PWM_PSC = 72MHz / ((ARR+1) x f) - 1
     例: f=10kHz 时 PWM_PSC = 72000/1000 - 1 = 71 (即 72/(100x10)-1)
   若同时改 PWM_ARR, 则 CCR(占空比)与百分比的对应关系会变, 需同步调整
   SetDuty 中的换算(现 ARR=99 时 CCR 数值即百分比)。

五、main.c 集成方式(当前工程实测布局)
--------------------------------------------------------------------------------
   初始化顺序: OLED_Init(); Key_Init(); PWM_Init(); ADCx_Init(); Timer_Init();
   主循环:    Key_Service() 中根据按键动作调用 PWM1_SetDuty/PWM2_SetDuty,
              修改立即生效; OLED 第1/2行显示 ADC 实测的频率与占空比。

六、验证情况(实测预期)
--------------------------------------------------------------------------------
 - 上电后 PA6/PA7 均有 1kHz、50% 方波输出(示波器测量);
 - 接回环线(PA6→PA4, PA7→PA5)后 OLED 显示 F≈01000Hz, D≈050%;
 - 单击 Key1: 设定占空比 +10%, 约 1s 内 OLED D1 跟随新值;
 - 占空比 0%/100% 时输出恒低/恒高(方波消失, ADC 显示 0Hz 属正常现象)。

七、注意事项
--------------------------------------------------------------------------------
 1. CCR=100(占空比100%)时无翻转沿, 过零计数法会读到 0Hz——用示波器
    观察即恒高电平, 属正常; 测频实验建议占空比保持在 10%~90% 之间。
 2. 输出为 3.3V 逻辑电平, 直接驱动 LED 需串限流电阻, 驱动电机等大负载
    必须外加驱动电路。
 3. 备用驱动 HardWare/LED.c、AD.c 使用 PA0~PA3, 与本模块引脚无冲突。
 4. 移植到其他工程: 拷贝 User/PWM.c、User/PWM.h, 在 main 中调用
    PWM_Init() 即可; 注意系统时钟必须为 72MHz(否则频率按比例偏移)。
